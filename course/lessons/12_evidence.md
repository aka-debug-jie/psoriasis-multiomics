# 12｜证据评分与覆盖热图

本章整合的是一份固定的科研重建结果快照。公开版第 05、06、11 章采用不同的教学输入，运行结果不会自动回写本章证据表。课堂 PGS 和 Cox 示例也不提供 UK Biobank 验证证据；汇总时应保留每一列的实际来源。

## 输入

本课有两组输入。`author_score_input.tsv` 保留作者主表的 29 行、PWAS 方向、九个原始证据标记和作者报告的 tier 字段。`primary_candidates_input.tsv`、`candidate_evidence_input.tsv` 和 `candidate_context_input.tsv` 来自研究最终数据，记录七个重新筛选候选的入选信息、证据覆盖状态及上下文。

作者评分按 `sensitivity`、两类 SMR、两类 PGS、bulk、single-cell、colocalization 和 PPI 九个槽位逐项重算。作者报告总分只用于和九项之和比较。七个重新筛选候选的 UKB PGS 项缺失，因此课程只展示各证据的覆盖状态，不为这七个候选计算作者可比总分。

## 问题

1. 九个证据槽位分别怎样根据 PWAS 方向记分？
2. 原始标记为空、方向相反、方向混合和支持信号，在热图中如何区分？
3. “未评估”与“已评估但未支持”有什么不同？
4. 为什么七个重新筛选候选不能补算一个与作者总分可比的总分？

## 关键代码

```r
if (slot %in% c("coloc", "ppi")) {
  return(as.integer(grepl("√", value, fixed = TRUE)))
}
if (reference == "+") {
  if (slot %in% c("bulk", "single_cell"))
    return(as.integer(grepl("↑", value, fixed = TRUE)))
  return(as.integer(grepl("+", value, fixed = TRUE)))
}
```

其余负方向判断、作者分数解析和九项求和遵循同一研究脚本中的规则。热图的“方向冲突”表示原始方向标记只出现与 PWAS 相反的方向；若一个原始标记同时含预期和相反方向，则按原规则计分，并单独标为“方向混合”。

## 结果解读

29 行作者报告分数均与九个槽位的重算之和一致。作者热图保留逐槽原始标记，并区分计分支持、方向冲突、方向混合、未计分和未报告值。出现“方向混合”时，是否计分仍由原评分规则决定；图中的分类仅帮助阅读，不改变贡献值。

七个重新筛选候选共有 63 个证据组件记录：21 项为已观察到支持，20 项在已测试数据中未支持，19 项不可评估，3 项覆盖不完整且未观察到支持。覆盖热图沿用最终证据矩阵的状态定义；未评估保留为 NA，不当作零或反对证据。上下文表保留细胞和 pseudobulk 的原始方向描述。

七个候选的 UKB psoriasis 与 PsA PGS 值均缺失，综合表的重建总分也均为 NA。因此输出只呈现证据覆盖与原始上下文，不为七个候选计算或补齐可与作者总分比较的总分。

## 练习与参考答案

### 练习一：规则阅读

某候选 PWAS 方向为 `+`，`bulk` 标记为 `↑`；另一候选 PWAS 方向为 `−`，`bulk` 标记为 `↑`。按本课规则，两项各记多少？

**参考答案：** 第一项记 1，第二项记 0，并显示为方向冲突。bulk 使用上、下箭头；普通遗传证据槽位使用正、负号。

### 练习二：结果分类

在候选证据热图中，`not_evaluable` 与 `not_supported_in_tested_data` 有何不同？

**参考答案：** `not_evaluable` 表示没有可用于评估的观测，支持值保留 NA；`not_supported_in_tested_data` 表示该项已有完整测试，但没有达到相应支持条件。两者不能都解释为阴性结果。

### 练习三：完整性检查

为什么作者 29 行可以比较重算总分，而七个重新筛选候选不计算同类总分？

**参考答案：** 作者主表提供了九个评分槽位和作者报告分数，能够逐项复刻并核对算术。七个新候选缺少 UKB PGS 项，且研究综合表将总分保留为 NA；缺失项不能按 0 补入，也不能据此宣称与作者总分可比。
