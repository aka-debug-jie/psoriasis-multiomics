# 第 10 课：功能富集、STRING 网络与药物关联

## 问题与输入

7 个候选基因是否集中在某些功能条目中？候选蛋白在 STRING 网络和药物资料里有哪些关联？机会背景由 2,045 个可用蛋白组成，映射去重后为 2,043 个 GeneID。候选集和背景先统一到 GeneID；各 ontology 再按自身注释覆盖形成背景，不能把未注释基因当作该家族的阴性注释。

## 核心步骤

输入 term–gene 长表来自 GO 注释及 GO 本体，GAF 注释按 `is_a` 和 `part_of` 关系向祖先传播，并排除否定注释。Reactome 使用通路基因注释。对 BP、MF、CC、Reactome，先分别计算完整的已注释背景与候选覆盖，再保留背景 term 大小 10–500 的检验项；交集为零的 term 也保留。R 中可直接看到超几何右尾计算 `phyper(k-1, K, N-K, n, lower.tail=FALSE)`，其中 N 是家族注释背景、K 是 term 背景大小、n 是有家族注释的候选数、k 是交集数。每个家族各自做 BH 校正，避免把四类检验混成一个校正家族。

本次测试 term 数依次为 BP 1,888、MF 338、CC 282、Reactome 342；FDR<0.05 的条目数为 2、0、0、0。STRING 图展示候选与邻居的功能关联边。药物表把证据分成直接靶点、复合物/家族组分和 STRING 网络关联：本例分别为 0、5、53 条。网络关联只表示资料库中的网络联系，不能解释成药物直接结合候选蛋白或已有药效。

## 结果图怎么读

富集图横轴是 −log10(BH FDR)，虚线对应 FDR=0.05；点大小表示候选命中数，颜色区分功能家族。只把通过阈值的条目称为显著，其他条目可作描述但不作确认结论。网络图中的高亮节点是候选，连线反映 STRING 综合关联分数；它不是方向性通路图。药物图按候选展示不同证据类别的独立药物数，直接靶点为零时不能把网络条数填入该栏。

## 练习与答案

1. **为什么 GO 背景不能直接用全部 2,043 个 GeneID？** 每个 ontology 的已注释覆盖不同；超几何检验的 N 与 n 必须按该家族的完整注释集合计算，再筛 term 大小。
2. **若把 term 大小上限从 500 改成 300，哪些步骤要重做？** 重新筛检验项、重算这些项的 P 值和该家族 BH；背景注释覆盖本身不变。不可沿用旧 FDR。
3. **53 条网络药物关联是否表示 53 种药直接作用于候选？** 不是。直接靶点为 0、复合物/家族组分 5、网络关联 53；三类必须分开解释，网络关联不证明直接结合或药效。
