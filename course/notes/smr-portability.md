# SMR 的并列位点次序

课程使用 SMR 1.4.3 的固定源码版本，并为 HEIDI 的位点选择加了一条确定的并列规则：当两个位点的 `|Z|` 完全相同时，按当前选择步骤的输入索引排列。LD 阈值、工具筛选阈值和统计公式保持原值。

## 为什么要规定次序

ERAP2 示例中，rs12189125 与 rs1974871 的表达效应及标准误完全相同，`Z=-28.7809042484`；两者的参考 LD 为 `r²=0.99237`。rs1230361 与 rs1235617 也是完全并列，参考基因型相同。疾病 GWAS 给出的标准误却有所不同。

原程序只按 `|Z|` 比较，没有规定并列位点的次序。不同标准库可以排出不同顺序；随后 LD 剪枝又会按索引处理度数相等的节点，因此保留的代表位点可能不同。

在本例的原版对照中，进入剪枝的 352 个位点、7,841 条相关边和节点度数相同。并列位点的索引次序准确解释了移除列表的差异。课程将比较器写为：

```cpp
const double za = fabs(smrwk->zxz[a]), zb = fabs(smrwk->zxz[b]);
return za == zb ? a < b : za > zb;
```

## 默认输入的对照

| 工具与运行环境 | ERAP2 HEIDI P | LIPA HEIDI P |
|---|---:|---:|
| 原版，Linux / Windows | 0.2480520 | 0.2011178 |
| 原版，Intel / Apple Silicon Mac | 0.2465839 | 0.2011178 |
| 课程修改版，四种环境 | 0.2423640 | 0.2011178 |

每种环境均以 1、2 线程各运行两次。课程修改版的全部结果字段一致；Windows 文本使用 CRLF 换行，统一换行后文件哈希也一致。ERAP2 和 LIPA 的 HEIDI 位点数分别仍为 20、9，SMR 效应、标准误和 P 值保持原值。

课堂参考值采用课程修改版，原 Linux 对照另存为 `data/smr/reference_original_linux.tsv`。科研结果快照保留其原有工具和分析记录。这个规则用于固定选择次序；读结果时，仍分别判断表达关联与异质性。

源码基于提交 `eedb1a62ba4c66ab0b09acd0205876955a803f18`。补丁、实际源码和构建参数随课程发行；项目仓库的 `scripts/patch_smr_order.py` 给出修改，`smr-portability.yml` 保留原版、只加日志版和确定次序版的对照流程。
