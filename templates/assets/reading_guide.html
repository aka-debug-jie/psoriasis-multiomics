赋值列取行列逻辑匹配分类公式函数循环不确定性字段课程辅助函数

赋值：把结果放进对象

<- 把右侧的值存到左侧对象名里；后续代码可以继续使用这个名字。

demo_table <- data.frame(gene=c("A", "B"), sample_1=c(10, 20))
n_gene <- nrow(demo_table)

列：用 $ 取字段

数据框后接 $列名，得到该列的向量；列名要和表里的字段一致。

demo_table$gene
demo_table$sample_1

取行和列：[行, 列]

逗号前选行、逗号后选列。空白表示保留全部；负下标表示排除相应位置。选单列时，drop=FALSE 保留表格形状。

demo_table[1, , drop=FALSE]
demo_table[, -1]
demo_table[, "gene", drop=FALSE]

逻辑条件：筛选时看清缺失值

== 比较是否相等，& 表示两个条件都满足，| 表示满足其一，%in% 检查是否属于一组值。NA 是缺失，不能当作 0。

keep <- dat$p < 0.05 & dat$group %in% c("A", "B")
dat[!is.na(keep) & keep, ]

匹配：按编号查位置

match(x, table) 对 x 中每个编号，返回它在 table 的位置。找不到时返回 NA，后续取值要留意缺失。

pos <- match(query$rsid, reference$rsid)
found <- reference[pos, ]

分类变量：factor 与水平

factor 把文本或编码标成分类变量；levels 列出它允许的类别。水平顺序影响显示顺序；本课程使用默认处理对比时，第一个水平也是模型的参照组。

group <- factor(dat$group, levels=c("control", "case"))
levels(group)

公式：~ 描述模型结构

在 R 模型公式中，左侧通常是响应变量，右侧写解释变量；右侧的 1 表示截距，0 表示不含截距。具体含义要结合所在模型函数理解。

fit <- lm(y ~ group + age, data=dat)
fit_no_intercept <- lm(y ~ 0 + group, data=dat)

函数：参数进去，对象出来

括号里是传给函数的参数，赋值语句会把返回对象保存起来。library 加载包，source 执行本地 R 脚本；pkg::函数 指明函数来自哪个包。

library(ggplot2)
result <- stats::median(x, na.rm=TRUE)
source("R/common.R")

重复处理：for、lapply、vapply

for 逐项执行代码；lapply 对每项调用函数并返回列表；vapply 也逐项调用，但要求结果符合给定类型和长度。

for (i in seq_along(files)) print(files[i])
means <- lapply(groups, mean)
means_num <- vapply(groups, mean, numeric(1))

不确定性字段：先认名称

SE 常指标准误，CI 常指置信区间。这里仅帮助辨认字段；它们具体怎样得到、如何解释，要看课程模型与上下文。

result$se
result$CI_log_low
result$CI_log_high

课程辅助函数：查定义再看用途

read_tsv 读取制表符分隔文件；course_table 便于查看表格的部分行或指定列；save_plot 保存图。allele_sign 对齐等位基因方向并返回符号或缺失值，givw 按输入效应、标准误与相关矩阵计算结果字段。具体参数和处理请读 R/common.R、R/genetics.R 或 R/notebook_support.R；统计解释留在主课。

dat <- read_tsv("data.tsv")
course_table(dat, columns=c("gene", "beta"))
save_plot(p, output, "result")
