运行与退出说明

回到解压后的课程包根目录，打开适合电脑系统的运行入口：Windows 使用 .bat，Mac 使用 .command。课程使用包内置环境，开始学习不需要另外安装软件。

Mac 首次打开

首次打开时，macOS 可能要求批准这个下载文件。按系统提供的“打开”或针对该文件的“仍要打开”操作；学校管理的电脑若限制运行，请联系管理员。无需另装 R 或 Jupyter。

结束学习

在 Jupyter 页面选择 File → Shut Down 关闭服务。也可以切回启动课程时打开的运行窗口，按 Ctrl+C。

练习文件

课程运行产生的结果保存在 课程资源/work/results/。Windows 按 Ctrl+S、Mac 按 Cmd+S 保存 Notebook；下次打开会保留代码和已保存的输出。已保存输出不代表 R 内核仍保留变量。

想从原稿重新练习，可在初始化后运行 course_fresh_notebook('01') 创建第 1 章的新副本，再从左侧文件列表打开。该操作不覆盖已有练习。

完成一轮分析后，运行 course_snapshot('baseline', settings) 保存本课结果和参数。快照放在 课程资源/work/snapshots/，再次保存会建立新目录。

界面操作和排错示例见第 0 章。

读代码时遇到陌生符号，可查看R 代码阅读速查。各章的“展开看”说明可按需打开，代码格仍按页面顺序执行。

返回课程入口

第一次运行前

请完整解压到本地可写目录。Windows 遇到目录过深时，会自动选择当前用户的短缓存目录存放运行环境；Notebook 和结果仍留在课程文件夹。入口固定使用内置 R 4.4.2，不需要修改电脑上已有的 R 或 Python。

启动中断时

  • ARCH：重新选择与处理器匹配的课程包。
  • PATH 或 CACHE：把完整文件夹移到 D:\course 等较短的本地路径。
  • WRITE：移到自己有写入权限的文件夹。
  • SPACE：释放对应磁盘空间后重试。
  • PACKAGE：重新下载并解压到新文件夹，原有练习先保留。
  • BUSY：等待另一个启动窗口准备完成后，再打开入口。

首次准备意外中断后，可重新打开运行入口。反馈问题时附课程版本、系统和错误编号；移除个人路径与令牌，不要发送整个 work 文件夹。
