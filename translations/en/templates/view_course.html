Course Portal

Start with the course previews, which include results, or open a blank practice notebook and run the R code cells yourself. If this is your first time using Jupyter, begin with Chapter 0.

Get started

  1. After extracting the package, open the “Run Course” launcher in this folder. On Windows, run .bat; on Mac, run .command.
  2. Wait for Jupyter to open in your browser, then open 00_start.ipynb in the course folder.
  3. Follow Chapter 0 to learn the interface, then press Shift+Enter to run cells one by one. There is no output when you first open the notebook; results appear after you run the cells.

The launcher uses the environment bundled with the course package, so no additional software installation is needed. Practice results are saved in 课程资源/work/results/. After saving a Notebook, your changes and outputs will still be there when you reopen it; you can also save a copy to continue practicing.

Choose the package for your computer

The course package comes in versions for Windows, Intel-based Mac, and Apple silicon Mac. Choose the archive that matches your operating system and processor. The first time you open the launcher on a Mac, follow the system prompt to confirm.
