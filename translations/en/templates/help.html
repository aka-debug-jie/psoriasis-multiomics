Run and Shut Down

Return to the extracted course package folder and open the launcher for your computer: use .bat on Windows or .command on Mac. The course uses its bundled environment, so you do not need to install additional software to get started.

Opening on a Mac for the first time

The first time you open it, macOS may ask you to confirm that you want to run it. Follow the system prompt to open it; you do not need to install software or disable or change system security settings.

Finish your session

On the Jupyter page, choose File → Shut Down to stop the service. You can also switch back to the run window opened when you started the course and press Ctrl+C.

Practice files

Results generated while running the course are saved in 课程资源/work/results/. Press Ctrl+S on Windows or Cmd+S on Mac to save a Notebook; its code and saved outputs will remain when you reopen it. Saved outputs do not mean that the R kernel still retains its variables.

To practice again from the original, after initialization run course_fresh_notebook('01') to create a new copy of Chapter 1, then open it from the file list on the left. This does not overwrite existing work.

After completing an analysis, run course_snapshot('baseline', settings) to save this lesson’s results and parameters. Snapshots are stored in 课程资源/work/snapshots/; each new save creates a new directory.

For interface instructions and troubleshooting examples, see Chapter 0.

If you encounter an unfamiliar symbol while reading code, see the R Code Quick Guide. Open the “Expand” sections in each chapter as needed, and continue to run code cells in page order.

Before your first run

Extract the complete package to a local writable folder. Windows automatically uses a short per-user runtime cache when the course location is too deep. Your notebooks and results stay in the course folder. The bundled R 4.4.2 is used even if another R or Python is installed.

If startup stops

  • ARCH: choose the package for the correct processor.
  • PATH or CACHE: move the complete folder to a short local path such as D:\course.
  • WRITE: move it to a folder you can write to.
  • SPACE: free space on the indicated drive and retry.
  • PACKAGE: download and extract a fresh copy into a new folder; keep your previous work.
  • BUSY: allow the other startup window to finish, then reopen the launcher.

After an interrupted first preparation, open the launcher again. For an error report, include the course version, operating system and error code. Remove personal paths and tokens; do not send the entire work folder.
