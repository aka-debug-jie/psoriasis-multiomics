Assignment: store a result in an object

<- stores the value on the right under the object name on the left; later code can use that name.

demo_table <- data.frame(gene=c("A", "B"), sample_1=c(10, 20))
n_gene <- nrow(demo_table)

Columns: use $ to access a field

Append $column_name to a data frame to get that column as a vector. The column name must match a field in the table.

demo_table$gene
demo_table$sample_1

Select rows and columns: [row, column]

Select rows before the comma and columns after it. A blank keeps everything; a negative index excludes that position. When selecting one column, drop=FALSE keeps the table structure.

demo_table[1, , drop=FALSE]
demo_table[, -1]
demo_table[, "gene", drop=FALSE]

Logical conditions: account for missing values when filtering

== tests equality, & requires both conditions, | accepts either condition, and %in% checks whether a value belongs to a set. NA means missing and must not be treated as 0.

keep <- dat$p < 0.05 & dat$group %in% c("A", "B")
dat[!is.na(keep) & keep, ]

Matching: look up positions by ID

For each ID in x, match(x, table) returns its position in table. If there is no match, it returns NA; account for missing values when using the result.

pos <- match(query$rsid, reference$rsid)
found <- reference[pos, ]

Categorical variables: factor and levels

factor marks text or codes as a categorical variable; levels lists its allowed categories. Level order affects display order. With the default contrasts used in this course, the first level is also the model reference group.

group <- factor(dat$group, levels=c("control", "case"))
levels(group)

Formulas: ~ describes model structure

In an R model formula, the left side is usually the response and the right side lists explanatory variables. A 1 on the right indicates an intercept; 0 indicates no intercept. Interpret the formula in the context of the model function using it.

fit <- lm(y ~ group + age, data=dat)
fit_no_intercept <- lm(y ~ 0 + group, data=dat)

Functions: arguments in, objects out

Arguments passed to a function go inside the parentheses, and an assignment can store the returned object. library loads a package; source runs a local R script; pkg::function specifies which package a function comes from.

library(ggplot2)
result <- stats::median(x, na.rm=TRUE)
source("R/common.R")

Repeat an operation: for, lapply, and vapply

for runs code one item at a time. lapply calls a function for each item and returns a list. vapply also calls a function for each item, but requires results to match a specified type and length.

for (i in seq_along(files)) print(files[i])
means <- lapply(groups, mean)
means_num <- vapply(groups, mean, numeric(1))

Uncertainty fields: start with the names

SE commonly means standard error, and CI commonly means confidence interval. This is only a guide to recognizing fields; how they are calculated and interpreted depends on the course model and context.

result$se
result$CI_log_low
result$CI_log_high

Course helper functions: check the definition and then the use

read_tsv reads a tab-delimited file; course_table helps inspect selected rows or columns; save_plot saves a plot. allele_sign aligns allele directions and returns a sign or a missing value. givw calculates result fields from input effects, standard errors, and a correlation matrix. For exact arguments and behavior, read R/common.R, R/genetics.R, or R/notebook_support.R; statistical interpretation belongs in the main lesson.

dat <- read_tsv("data.tsv")
course_table(dat, columns=c("gene", "beta"))
save_plot(p, output, "result")
