# Source access for elkjs 0.9.3

JupyterLab includes the unmodified elkjs 0.9.3 distribution, licensed under
EPL-2.0. Its full licence is retained with the npm component notices.

The source and build instructions are available from
[kieler/elkjs at the npm gitHead](https://github.com/kieler/elkjs/tree/a8304cf79fde75bc2ab1a89d28320f53f8637436).
The [upstream release notes](https://github.com/kieler/elkjs/releases/tag/0.9.3)
identify ELK 0.9.1 and the additional [ELK change #955](https://github.com/eclipse-elk/elk/pull/955).
The ELK Java sources are available from the [ELK repository](https://github.com/eclipse-elk/elk),
including the [tree at that documented merge](https://github.com/eclipse-elk/elk/tree/7ca51784e42a24201f29bc13e458728b6fc61cdc).

The corresponding source downloads in this course release include the elkjs
source at its exact npm gitHead and an ELK source tree containing the documented
additional change, with their hashes. The upstream build uses a neighbouring
ELK checkout and does not record its precise revision, so these references are
source access information, not a claim of a bit-for-bit reconstruction of the
upstream JavaScript worker. The course has not changed the worker.
