# Contributing

Report a reproducible issue with the course version, operating system, chapter,
cell label, and the complete error message after removing personal paths and tokens.
Do not upload student work, clinical records, credentials, or the entire runtime folder.

Keep statistical changes separate from wording or display changes. Explain any new
data source, allele convention, sample unit, testing family, or parameter. Run the
relevant checks and record source versions. Both language editions should describe
the same computation. Preserve upstream licence notices.
