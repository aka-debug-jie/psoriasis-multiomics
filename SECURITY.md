# Reporting a security issue

Use GitHub's private vulnerability reporting feature on this repository for an
issue involving credentials, private information, or arbitrary code execution.
Do not post secrets in a public issue. Ordinary course errors belong in Issues
with personal paths and tokens removed.

The student launcher runs a local Jupyter server on 127.0.0.1 with a random token.
It does not send analysis results or diagnostic logs to this project. Shared
computers and managed-device security policies remain controlled by their owners.
